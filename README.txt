Birthday Gift Website — LEGO Surprise Edition
================================================

Files:
- index.html   Complete website.
- gift.svg     Standalone illustration of the gift box.
- gift.pdf     Temporary placeholder PDF.
- README.txt   This guide.

UPLOAD:
Put index.html, gift.svg and gift.pdf in the ROOT of your GitHub Pages repository.

TEST:
Open the GitHub Pages URL on an iPhone in Safari.
Tap OPEN THE GIFT.
Tap ENABLE MOTION and allow motion access.
Shake the phone until the bar reaches 100%.
The temporary gift.pdf will then open.

FINAL GIFT:
Replace gift.pdf with your real one-page PDF.
Keep the exact filename "gift.pdf".

NOTE:
The visible gift box is drawn directly in CSS, so no external image is required.
